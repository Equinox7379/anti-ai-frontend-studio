# NOTICE

This repository (anti-ai-frontend-studio v6.0.0-rc2) is a prompt-and-method work
package: design-method documents, descriptive tooling, templates, and calibration
cases for AI coding agents.

## Third-party methodological sources

- **taste-skill** — https://github.com/Leonxlnx/taste-skill (MIT License).
  Methodological inspiration: portable agent skill files, anti-slop rule bundling.
- **impeccable** — https://github.com/pbakaus/impeccable (Apache License 2.0).
  Methodological inspiration: slash-command design vocabulary, deterministic
  detection rules, unanchored review before evidence.

This package absorbs methodology ideas and public documentation concepts only;
no upstream source code is copied. The descriptive detector in `tools/` is an
independent implementation with its own rule set and test fixtures.

## Archived materials

`deep_library/` and `archive/` contain historical packages and external review
documents retained for provenance. They keep their original authorship and are
not part of the active method.
