# GPT 默认组合风险

这些材料都可能合法；危险在于它们不随 Brief 改变，成套自动出现。

## 配方 A：假高级编辑式

```text
#F4F1EA 或相近奶油底
+ 大型衬线／宋体标题
+ 砖红／陶土点缀
+ 发丝线、眉题、小编号
```

## 配方 B：反 slop 黑酸风

```text
纯黑／近黑
+ 荧光绿或朱红
+ 巨型 grotesk／等宽
+ 跑马灯、噪点、自定义光标
```

## 配方 C：报纸式无卡片模板

```text
零圆角
+ 密集分栏
+ 大量 1px 线
+ 01 / 02 / 03、角标、眉题
```

## 其他常见组合

- Inter + Playfair Display／Instrument Serif；
- 紫蓝渐变＋深色 mesh＋三等宽功能卡；
- 左侧栏＋四 KPI＋图表＋最近活动；
- Apple 式巨型居中标题＋玻璃导航＋Bento；
- Linear 式近黑＋Geist／Inter＋冷灰边框＋命令面板。

判断：逐项说明其项目来源。无法说明时，不要“弱化一点”，而是回到任务关系重做。
