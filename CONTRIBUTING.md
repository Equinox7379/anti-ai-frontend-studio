# Contributing

Contributions should be driven by one of:

1. A **reproducible design failure** — a case where the current method produced
   or failed to prevent a specific, documented problem.
2. A **real rendered case** — a before/after with actual rendered output, not a
   hypothetical improvement.
3. A **well-scoped improvement** — a bounded change to a template, detector rule
   (with fixture), or routing entry.

## Non-goals

- Adding more universal prohibitions or aesthetic bans.
- Scoring, ranking, or grading designs.
- Expanding the detector into a style enforcer.

## Process

1. Open an issue describing the failure or improvement with evidence.
2. Reference the affected file(s) in `core/`, `knowledge/`, `templates/`, or `tools/`.
3. Keep changes minimal and consistent with the existing structure.
