# 前端 Goal 施工任务书模板（云端设计完成后交给本地施工 AI）

> 使用者：云端设计／审核 AI。  
> 接收者：本地施工 AI。  
> 适用时机：页面方向、信息架构、视觉方案、关键代码或原型已经由云端完成，只剩真实工作区落盘、字体取得、浏览器／真机适配、相关测试、提交与获准推送。  
> 使用原则：删除所有不适用段落；不要为了“模板完整”保留空字段。

# 【项目名】·【本轮目标】正式施工任务书

## 1. Goal 模式施工约定

本任务采用 Goal 模式。你获得的是完成下述最终目标的持续授权，不是只做第一步的微型任务。

在本任务范围内出现的普通编译错误、类型错误、测试失败、CI 红灯、选择器失效、夹具不同步、字体路径、端口占用、响应式溢出、浏览器兼容、既有测试需要同步以及其他可逆问题，由你自行诊断、修复、验证和收口。不要因为普通红灯暂停，也不要要求 Owner 在多个 AI 之间转述下一步。

只有命中本任务末尾列出的“真正硬停止条件”时才允许暂停。除此之外，应持续执行到完成标准满足。

## 4. 剩余工作只能在本地完成的原因

本轮剩余工作客观依赖本地条件，包括：

## 5. 事实来源与优先级

发生冲突时按以下顺序处理：

1. Owner 当前轮明确要求；
2. 仓库或全局 `AGENTS.md`；
3. 本任务书；
4. 本任务列出的已批准设计／代码／测试制品；
5. 施工 AI 对具体 CSS、组件拆分和本机适配的局部专业判断。

不要重复粘贴整份 `AGENTS.md`。若本任务与其冲突，应先判断是否命中硬停止条件；不要静默选择其中一方。

## 9. 实施顺序

1. 读取 `AGENTS.md`、本任务书、已批准设计制品和视觉契约测试。
2. 先确认当前仓库、分支、工作树和运行方式。
3. 将云端已完成的代码／原型落入真实项目。
4. 取得本地必需资源；不得擅自用系统默认替换已批准字体或资产。
5. 运行最小定向测试，修复真实本机差异。
6. 在指定视口／设备完成主要路径验证。
7. 运行视觉契约测试；失败时修复实现，不得先弱化断言。
8. 查看实际 diff，删除临时文件和无关改动。
9. 按 Git 权限完成 commit／push。
10. 若任务含本地审核，调用 `luna_worker` 复核最关键、最容易遗漏的风险；主施工代理仍需自行复核。

## 12. 视觉契约测试纪律

- 视觉契约测试是已批准设计意图的可执行表达。
- 优先断言用户可见的结构、几何、关系和行为，不依赖私有 CSS 类名。
- 除非设计机制本身要求特定实现（例如互补 `clip-path`），否则不要锁死内部实现。
- 测试失败时先检查实现是否偏离设计；不得为获得 GREEN 擅自放宽容差、删除断言、改夹具或把真实内容换成更容易通过的内容。
- 设计意图确需改变时，停止修改测试，由云端先更新任务书和视觉契约。

## 13. 测试边界与反工程化要求

执行：

- 现有相关语法／构建检查；
- 能真实覆盖本轮风险的定向测试；
- 一次相关回归检查；
- 一次真实桌面／移动或真机检查。

针对实际发现的问题，可以补充一个最小复现测试并在修复后运行一次。

默认禁止：SHA-256、逐文件哈希、Manifest、证据 ZIP、Git Bundle、双 Worktree、多层提交重建、重复完整测试、几十次压力重复、截图堆积、视频、trace、冗长日志、大型发布门禁及与本 Goal 无关的长期治理。

当任务确实涉及不可逆迁移、数据恢复、供应链或制品完整性时，只采用直接降低该风险的最小保障。

## 15. 完成标准

只有同时满足下列条件，Goal 才算完成：

- 已落入正确工作区；
- 云端批准的设计与功能制品已完整接入；
- 本地必需字体／资源已正确落位；
- 构建与定向功能测试通过；
- 视觉契约测试通过；
- 指定桌面／移动／真机路径正常；
- 视觉不可变项没有被改变；
- 没有无关改动或临时文件进入提交；
- 已按当前授权完成 commit／push；
- 不存在真正硬停止条件中的未解决事项。

## 16. 真正硬停止条件

只有下列情况才允许暂停并联系 Owner：

- 继续执行可能损坏原始数据；
- 可能泄露密钥、隐私或受保护材料；
- 可能伤害无关项目或程序，且无法安全隔离；
- 必须执行未获授权的不可逆操作；
- 远端存在无法安全处理的真实冲突；
- 目标目录或仓库归属无法判断，任何选择都可能破坏无关内容；
- 必要凭据、写权限或唯一资源客观不可获得；
- 云端已批准的目标之间存在无法同时满足的真实矛盾；
- 实际环境证明必须改变公共接口、架构边界或主要设计方向才能继续。

以下通常不是硬停止条件：端口占用、Node／Java／Python 版本、普通测试失败、CI 红灯、CSS 溢出、字体路径、选择器失效、旧测试不同步、可逆 Git 问题和本地兼容差异。应在本 Goal 内自行解决。
