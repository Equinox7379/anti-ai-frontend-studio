# 成熟参考的正确用法

参考不是皮肤库。每个参考先记录：页面任务、信息拓扑、用户状态、可迁移机制、不可复制部分、证据范围。

## 使用顺序

1. 先完成页面真相和主关系。
2. 找任务相近的工作流参考。
3. 找交互或状态相近的参考。
4. 只有表达问题仍未解决时，选择一个表达参考。
5. 把参考翻译成因果句，再进入项目设计。

## 证据等级

- 官方规范、成熟产品表面：可以支撑工作流与交互。
- 经过深读的获奖项目：有限支撑表达。
- 目录级画廊：只证明设计世界很宽，不支撑具体决策。

## 反抄皮肤

禁止写“做成 Linear／Apple／Stripe 风”。应写：

```text
因为用户需要在同一对象上切换设计与开发任务，界面保持对象身份并改变工具层。
```

这类关系可以迁移；暗色、字体、圆角和品牌动效不能自动迁移。
