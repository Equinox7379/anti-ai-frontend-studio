# 中文排版、字体性格与数据

## 角色先于字体名

确定界面真正需要的 UI、阅读、数据、展示和标识角色。角色可以合并；每引入一个家族都要说明它独自完成什么工作。

## CJK-first

先用真实中文确定字面率、行高、标点、粗细与换行，再加入 Latin 和数据字体。不要让英文 starter font 决定页面，再把中文交给 fallback。

## 字体性格参数

完整记录：

```text
family / size / weight / width / tracking / line-height
numeral features / punctuation / wrapping / fallback
```

“换成更有态度的字体”不是完成。一个中性家族通过清楚的尺度、字宽和数字处理也能形成成熟人格。

## 数据测试串

```text
应纳税所得额 23,400,000.00 元
本期递延所得税负债为（1,280,450.75）元
借：长期股权投资  5,850,000.00
贷：银行存款      5,850,000.00
Policy-2025-A · IFRS 21 · CAS 19
```

检查千分位、小数点、括号负数、百分号、中文与版本号基线。金额比较通常右对齐并测试 tabular numerals；不要只写 CSS 属性而不确认字体支持。

## 高风险自动搭配

流行无衬线＋高反差展示衬线，以及“教育／文化＝大号衬线标题”等自动配对都需要真实品牌或内容依据。它们不是永久禁用，但不能由自由轴自动出现。

## 可读性

正文行长、行高和字重由实际字体、语言、密度和设备共同决定。操作型产品不应为了纤细高级牺牲 12—14px 下的清晰度；连续阅读也不应复制英文负字距和超紧行距。
