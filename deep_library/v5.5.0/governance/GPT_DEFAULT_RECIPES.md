# GPT 默认配方：合法材料，不得成为自由轴默认值

这不是一张“禁用颜色和字体”的黑名单。它记录的是当前生成模型在 Brief 没有明确要求时，最容易反复命中的三套完整配方。单个材料可以合理；未经选择的组合、跨项目重复和任务损害才是问题。

## 当前三套 AI Slop 默认值

### A. 奶油编辑式

```text
米白背景 #F4F1EA
+ 大型高反差衬线标题
+ 砖红／陶土色点缀
```

常见变体会把砖红换成鼠尾草绿，再加入发丝线、章节眉题和大片空白。若真实品牌、材料、阅读场景或既有资产不能解释整套组合，不能仅凭“高级、文化、书卷、手工”启用。

### B. 黑底酸性色

```text
纯黑或近纯黑背景
+ 荧光绿／朱红单色点缀
+ 巨型无衬线或等宽字体
```

它常被误当成“大胆、先锋、反模板”的万能答案。必须由品牌、环境光、内容和交互任务共同支持，不能只为了逃离浅色 SaaS 而使用。

### C. 报纸式去卡片

```text
发丝分割线
+ 零圆角
+ 密集分栏
+ 眉题、角标或 01 / 02 / 03
```

零圆角不等于没有卡片。直角底色栏目、边框分区和固定 padding 仍可能组成一墙方块。规则线、分栏和编号只有在真实编码顺序、时间、汇总、来源或编辑关系时才成立。

## 排版本身就是信息

`01 / 02 / 03` 只用于真实流程、时间轴、优先级或章节定位；交换顺序不影响理解时，不应编号。分割线只区分表格、汇总、来源、章节或状态。眉题、角标和标签必须提供标题不能承担的真实上下文，不能用来填视觉空白。

## 字体不是人格贴纸

`Inter + Playfair Display` 是高风险自动搭配：一个承担“现代”，另一个承担“高级”，不论项目为何都能被套用。它们不是永久禁用，但必须有真实品牌与任务依据。

展示字体若存在，必须说明角色，并对实际字重、字宽、字距、行高、换行与中英文混排作有意识的调校。正文必须在目标字号、长中文、标点、数字和回退状态下验证。操作型产品可以不设展示字体；字体性格也可以来自一个 CJK-first 家族的字重跨度、数字造型和细致排版，而不是强行配一套海报字。

## 只 Bold 一个地方

每个页面只批准一个主要 Signature 冒险。它优先是能改善任务的机制，例如连续计算式、证据追溯、共享尺度比较或错误断点。周围内容必须主动安静。

必要的 hover、focus、loading 属于状态反馈；除此之外，通常只保留一个作者性动效时刻。完稿前执行一次“香奈儿删减”：真实删除一个非必要容器、线、标签、颜色、阴影或动画，直到再删会损害任务。

## 使用边界

- Brief 明确要求且与主题、品牌和场景一致时，三套配方都可以合法使用。
- 低能力施工 AI 无权自行触发例外。
- 静态扫描只能发现已知信号，不能替代对真实页面和业务的判断。
- 此文件记录时代性风险；模型默认变化后应更新组合，而不是永久追杀某个材料。
