# 构图对比预算

页面需要差异才能形成层级，但同时使用所有差异会产生噪声。云端设计负责人为每个页面分配有限的对比预算。

## 七种对比轴

```text
scale       尺度
placement   位置与占幅
spacing     留白与邻近
surface     背景、边界与深度
color       明度、色相和饱和度
typography  字重、宽度、字体角色与数字特性
motion      状态变化与时序
```

标准产品页面通常选择 **2–3 个主轴** 建立 P0，其余保持克制。若七个轴都变化，页面多半在表演；若没有任何轴产生明显差异，页面会平。

## 焦点合同

```text
PRIMARY_FOCUS：用户第一眼必须看见什么
SECONDARY_FOCUS：随后需要理解或操作什么
QUIETEN：哪些标题、元数据、边界或状态应降低
CONTRAST_AXES：本页主要使用哪 2–3 个轴
DENSITY_ARC：页面从哪里收紧、在哪里停顿、在哪里达到峰值
```

## 对税务工作台的应用

- `placement`：税额形成脊柱横跨主工作区；
- `scale`：最终税额明显大于中间金额；
- `surface`：只有最终结果使用高对比表面；
- 其余标题、边界和说明保持安静；
- 色彩不再同时承担成功、导航、链接、调增和主按钮五种职责。

## 眯眼校验

将截图缩小或眯眼观察。理想结果不是“所有东西都看得见”，而是：主焦点明确、次焦点可找，其余区域形成支撑。若最亮的是空白、导航或无关按钮，构图失败。

## 表面轴的约束

选择 `surface` 作为对比轴时，不等于批准多个高对比矩形。说明具体只有哪个对象需要表面，以及其余区域如何退回画布。最终结果也可以通过尺度、基线和会计汇总线成为峰值，不必默认使用深色块。
