# 从“干净但平”到有主张：Conviction Pass

Conviction Pass 只用于结构基本正确、模板味已降低，但页面仍像高保真线框稿的情况。它不是隐藏重设计，也不是添加特效。

## 先诊断平淡来自哪里

| 诊断 | 可见症状 | 正确修复 |
|---|---|---|
| 无功能焦点 | 用户只能逐行阅读，不能一眼看懂核心关系 | 把核心因果、比较、证据或进度做成可操作机制 |
| 对比被平均分配 | 标题、金额、状态和动作都在中等强度 | 选一个 P0，降低其余区域 |
| 留白没有职责 | 大片空白包围小灰字 | 重新建立密度弧，不是简单填满 |
| 页面缺少峰值 | 每个区块使用相同间距、边界和节奏 | 在任务转折或结论处形成一次密度／尺度变化 |
| 动作与状态分离 | 重要动作漂在角落，结果在另一处 | 让对象、状态和动作形成邻近关系 |
| 领域关系只在文案中 | 遮住标题后看不出为何是税务、审计或学习系统 | 将关系转成结构和交互 |
| 反 AI 规则压平一切 | 为避免卡片、颜色和字体，所有层级都被削弱 | 恢复有限但明确的视觉差异 |

## 单一放大原则

一次 Pass 只放大一个已经被项目批准的机制。例如：税额形成脊柱、证据追溯链、方案差异矩阵、风险到程序映射、学习掌握曲线。将它做完整，然后让周围更安静。

禁止同时：换字体、加渐变、改全站背景、增加四种状态色、添加插画和入场动画。这不是坚定，而是换一套皮肤。

## 三个强制问题

1. **去文案后，骨架还能表达这个页面为何重要吗？**
2. **删除这项机制，用户的判断、比较、追溯或操作是否真的变差？**
3. **为了让它成为主角，具体有哪些元素被降低了？**

第三个问题若答不出来，通常意味着页面只是“又加了一个亮点”。

## 停止条件

- 五秒内能说出页面对象、核心关系和下一步；
- 眯眼后只有一个主焦点和最多一个次焦点；
- 机制参与真实数据或操作，不是静态插画；
- 现有品牌和熟悉交互未被无授权替换；
- 相同状态前后截图能解释改善，而不是只有“更好看”。

## 平淡修复的禁区

不要把功能焦点切成一排相同方块，也不要把最终结果放进深色卡片作为自动解决方案。功能焦点可以通过连续公式、共享基线、列宽、尺度、留白、就地展开或空间路径成立。若眯眼后先看到矩形轮廓而非关系，Conviction Pass 失败。
