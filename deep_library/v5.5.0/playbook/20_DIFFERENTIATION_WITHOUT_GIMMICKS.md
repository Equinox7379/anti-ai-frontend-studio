# 不靠噱头建立项目识别度

识别度优先来自功能结构，而不是奇怪字体、随机非对称和装饰动效。

| 来源 | 可形成的识别度 | 不合格替代 |
|---|---|---|
| 独特对象关系 | 可追溯计算链、认定—证据链、实体依赖图 | 加一个行业图标 |
| 独特操作 | 就地比较、局部回溯、错误节点补强 | hover 上浮和磁吸按钮 |
| 独特数据 | 金额、小数、版本、时序、来源的专门对齐 | 巨大 KPI 数字 |
| 独特状态 | 草稿、过期、证据不足、口径冲突的明确语法 | 一排彩色 Badge |
| 独特内容节奏 | 分析、判断、练习、反馈密度随任务切换 | 每节同样标题与横线 |
| 真实品牌资产 | 已有字标、色彩、摄影或材料 | 临时寻找“少见字体” |

只有在功能结构已经足够明确后，才考虑一个有限的表达性决定。一个页面不需要强行拥有“记忆点”；可长期使用、关系清楚和细节稳定本身就能产生高级感。
