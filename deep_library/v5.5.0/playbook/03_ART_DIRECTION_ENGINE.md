# 项目专属艺术指导引擎

艺术指导不是选择“极简、编辑、Apple、Linear、粗野主义”之一，而是为项目建立一组能够持续解释的视觉原则。

## 视觉来源五层

| 来源 | 可提取内容 | 示例 |
|---|---|---|
| 品牌资产 | 已有颜色、字形、摄影、图标和语气 | 只使用真实存在的资产 |
| 领域物件 | 表格、仪表、档案、地图、谱面、时间码 | 提取功能逻辑，不复制外观 |
| 数据行为 | 比较、汇总、追溯、异常、进度、分支 | 决定线条、密度和状态 |
| 工作环境 | 长时间阅读、快速录入、移动训练、暗室观看 | 决定亮度、尺寸和输入方式 |
| 平台约束 | 键鼠、触屏、离线、低性能、打印 | 决定交互和材质成本 |

## 七个艺术指导轴

每个项目都应明确几何、对比、节奏、表面、字体、色彩和运动。每个轴写一个项目事实和一个可执行规则。例如“用户连续比较金额”可以转化为“金额列共享右对齐与等宽数字，汇总线只在数学层级变化时出现”，而不是“使用金融蓝”。

## 视觉原则的合格格式

```text
来源事实：审计结论必须能回到具体证据。
视觉原则：所有结论旁保留可操作的证据引用，展开后保持原阅读位置。
禁止替代：不使用单独的绿色‘证据可靠’徽章冒充追溯关系。
```

## 唯一记忆点

记忆点应优先是功能机制。例如实时展示计算如何从来源项汇入最终税额，或让一道审计题在提交后点亮判断链断点。装饰性巨字、奇怪字体、噪点、自定义光标和无意义动画不是功能记忆点。

## 反参考

每个方向必须写至少两个反参考，描述不能出现的骨架或气质。反参考要具体到组合，例如“不得出现奶油底＋宋体大标题＋墨绿发丝线的编辑式课程页”，而不是只写“不要 AI 味”。
