# 只 Bold 一个地方：Signature、动效与香奈儿删减

优秀界面需要确信，不需要到处表演。标准或重大页面只批准一个主要 Signature，其他区域用安静、稳定的产品语法支持它。

## 合格的大胆动作

优先选择能改变理解、判断、操作、验证或记忆的功能机制，例如连续税额形成式、结论到证据的追溯路径、共享尺度的方案差异、错误断点定位或版本恢复轨迹。

纯展示字体、巨型色块、渐变背景或滚动动画可以是材料，但不能代替功能机制。

记录：

```text
ONE_BOLD_MOVE = <唯一主要动作>
TASK_EFFECT = <它如何改善任务>
QUIET_ZONES = <哪些元素主动降低>
```

若无法指出周围哪些内容变安静，所谓 Signature 多半只是又增加了一层噪声。

## 一个作者性动效时刻

普通 hover、focus、loading、错误反馈属于状态语法，不计入上限。除此之外，页面通常只保留一个经过编排的入场、展开、切换或反馈时刻。禁止每节飞入、所有卡片上浮、数字统一滚动和背景持续漂移。

## 香奈儿删减

完稿前必须真实删除一件并非任务所需的饰品，候选包括：

- 一个无职责容器；
- 一条可由空间替代的线；
- 一个重复状态标签或眉题；
- 一种没有独立语义的颜色；
- 一个装饰图标、阴影或入场动画。

记录：

```text
REMOVED_ACCESSORY = <实际删除了什么，以及为什么任务不受损>
```

若删完任务反而变差，恢复最后一项并停止。删减不是把页面变空，而是让唯一重要动作更清楚。
