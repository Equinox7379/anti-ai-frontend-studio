## 一、这是什么

一套让 AI（ChatGPT / Claude 等）生成前端时**不再输出模板化 AI 味**的完整工作体系。核心思路一句话：

> 生成端用"设计宪法 + 五轴抽签 + 默认值供述"锁死数值；验收端用"特征库 + 可判定约束 + 人工 3 秒对照"检查产出。负面禁令只管审查不管生成，所以模型指令全部正向数值化。

## 四、开工流程（压缩版）

1. 宪法贴进模型项目指令（常驻）
2. 抽卡（10 张整卡随机抽 1，或跨站混抽）→ **待落纸槽位由人定案**（P 轴 / A 轴绝不能交给模型——实战证明模型落纸收敛到安全解）
3. 模型输出默认值供述表 → 人工逐项确认/替换 → 完整 CSS 变量块落纸
4. 分区块生成，每块停下等人工反馈
5. 人工修改后让模型归纳候选条款，**等量交换**回写宪法（加一必并一）
6. 验收：产出页与真实参考并排 3 秒对照；模型只做描述式预筛，**自评不可终审**
