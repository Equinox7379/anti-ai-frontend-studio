# 精工与交付：把方向做成可靠作品

## 1. 精工不是隐藏重设计

方向不成立就返回结构阶段；方向成立后才做精修。不要借“polish”偷偷换字体、色板、信息架构或品牌世界。

## 2. 精工检查

### 层级与节奏

- 五秒内可识别主任务、当前状态和主要动作；
- 同组更紧、跨组更松，章节转换有停顿；
- 密度随入口、阅读、数据、决策和操作变化；
- 大空白不能包围过小灰字造成漂浮。

### 字体与数字

- 同角色在不同页面和状态保持一致；
- 中文标题、标点、中英文混排、长词与回退字体实测；
- 金额、百分比、日期、版本号按任务使用等宽或 tabular numerals；
- 数字列共享对齐，小数位和负数规则稳定；
- 只加载真实使用的字体与字重，避免字体加载造成破坏性重排。

### 对齐与边界

- 检查光学中心，不只看几何中心；
- 图标、文字、按钮、输入框、数字和标点的基线一致；
- 每条线、每个背景面、每个阴影有职责；
- 浏览器默认的文本选择、焦点环、链接下划线、滚动条和光标也属于成品。

### 状态与恢复

按页面适用性完成：

```text
default / hover / focus-visible / active / selected / disabled
loading / empty / error / success / permission / offline
```

状态文案说明发生了什么、受影响内容和下一步。不要用彩色胶囊替代状态含义。

### 响应式与输入

至少验证主要桌面和移动尺寸；高风险时再补平板、320px、200% 缩放或真机。触控区、键盘顺序、抽屉焦点返回、长中文和系统字体缩放必须可用。

### 动效与性能

- 动效有明确事件与因果；
- 不使用 `transition: all`、统一上浮或全页 stagger 作为默认；
- 可中断，快速重复操作后状态正确；
- reduced motion 保留理解，不只是把时长缩短；
- 避免明显布局抖动、字体闪烁和图片占位变化。

## 3. 交付物

无上下文 AI 完成本轮后，至少提供：

```text
PROJECT_DESIGN.md          简短记录本项目设计判断
实际源码／可运行原型       不是只给方案
FIRST_RENDER.*             工具允许时保存第一版代表截图
FINAL_RENDER_DESKTOP.*     修正版桌面截图
FINAL_RENDER_MOBILE.*      修正版移动截图
必要测试或验证结果         与本轮风险相称
```

最终说明保持简短：

```text
做成了什么
核心设计命题与功能机制
第一版暴露了什么问题
实际修正了什么
验证了哪些视口／状态
哪些事项因工具限制仍未验证
```

## 4. 本地施工交接

当云端或当前 AI 已经完成设计、代码／原型和测试设计，而真实仓库落盘、字体二进制、Windows／真机或 Git 写权限必须在本地完成时，使用：

```text
templates/LOCAL_IMPLEMENTATION_TASK.template.md
templates/VISUAL_CONTRACT_TEST.template.md
```

任务书必须写清：Goal 持续授权、云端已完成清单、只能本地完成的客观原因、项目视觉不可变项、允许的局部自由、最少验证、Git 权限和真正硬停止条件。本地 AI 不再重新选设计方向。

视觉契约只编译真正重要的设计意图，例如：同位互补裁切、主工作区比例、金额对齐、移动端重排、无横向溢出和焦点返回。审美好坏不能伪装成自动测试。

## 5. 风险相称

局部文字、间距和按钮状态不需要完整研究与全站截图；页面骨架、字体体系、关键流程和多端重构需要更充分验证。不要默认生成哈希清单、证据 ZIP、双 Worktree、重复完整测试或大型门禁。

## 6. 完成定义

本轮可以结束，当且仅当：

- 用户任务真实成立；
- 页面不是用解释弥补结构；
- 第一版已经渲染并完成实际修正（工具允许时）；
- 主要桌面、移动和高风险状态无明显破坏；
- 没有虚构数据、状态、版本或品牌资产；
- 交付物可以被继续运行或落盘；
- 限制被准确说明，而不是被自评分掩盖。

## 7. 用户反馈后的聚焦改进

已有页面收到反馈时，优先使用 `DESIGN_VERBS.md` 将自然语言转成一个有边界的 pass：

```text
加力 / 收声 / 提炼 / 加固 / 精修 / 澄清／重述 / 适配 / 体检
```

先写目标、必须保留项和停止条件。不要把“精修”偷换成重设计，也不要把“适配”误解为改文案。需要比较变体时，可按需使用 `optional/LIVE_VARIANT_LOOP.md`；最多两个变体，同状态、同数据、同视觉世界，接受后删除其余临时代码。
