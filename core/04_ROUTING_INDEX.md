# 按需深读路由

默认只读核心文件。根据主任务，从 `knowledge/` 选择最多两个文件；复杂项目再追加。不要因为资料存在就全部加载。

| 当前问题 | 优先深读 |
|---|---|
| 不知道内容应怎样变成界面 | `knowledge/01_RELATION_TO_FORM.md` |
| 页面层级平均、空白漂浮、构图平 | `knowledge/02_COMPOSITION_HIERARCHY_SPACE.md` |
| 卡片墙、方块多、直角栏目墙 | `knowledge/03_SURFACE_RECTANGLE_DISCIPLINE.md` |
| 中文字体模板化、金额难比较 | `knowledge/04_TYPOGRAPHY_CJK_DATA.md` |
| 配色、阴影、图标和材质失控 | `knowledge/05_COLOR_MATERIAL_ICON.md` |
| 状态、动效、移动端或错误恢复 | `knowledge/06_MOTION_STATE_RESPONSIVE.md` |
| 想找成熟参考但担心抄皮肤 | `knowledge/07_REFERENCE_METHOD.md` + `references/REFERENCE_ATLAS.md` |
| 页面没明显 AI 味但平平无奇 | `knowledge/08_EXCELLENCE_AND_CONVICTION.md` |
| 复杂专业任务担心“简化过头” | `knowledge/09_COGNITIVE_LOAD_LENS.md` |
| 用户说“更大胆／更安静／润一下” | 根目录 `DESIGN_VERBS.md` |
| 同一页面想比较少量真实变体 | `optional/LIVE_VARIANT_LOOP.md` |
| 多页面项目需要稳定产品事实 | `templates/PRODUCT_CONTEXT.template.md` |
| 需要在不同 Agent 平台使用 | `platform/PLATFORM_ENTRYPOINTS.md` |

改版任务先查看现有页面、相邻流程、共用 Token 与真实状态；新页面才从项目真相建立视觉世界。

第一版渲染后依次进入：

```text
POST_RENDER_REVIEW.md
POST_RENDER_EVIDENCE_AND_REVISE.md
```

A 通道的无锚定设计判断必须先保存，之后才可读取特征库或运行检测器。
